Forja 0.2.3 trae una paleta de bloques con bibliotecas de dibujos, el polaco como idioma nuevo y comandos que funcionan también con el teclado griego.
*Forja 0.2.3 brings a blocks palette with drawing libraries, Polish as a new language, and commands that also work with the Greek keyboard.*

## Español

### Novedades
- **Paleta de bloques:** abre una carpeta de dibujos o un archivo como biblioteca, filtra sus bloques, míralos en iconos de varios tamaños o en detalle, y haz clic en uno para colocarlo. Puedes repetir la colocación o insertarlo ya descompuesto.
- **Polaco:** la interfaz está disponible en polaco.
- **Teclado griego:** un comando escrito con la distribución griega activa (por ejemplo ΛΙΝΕ) funciona igual que su nombre latino (LINE).
- **Herramientas adicionales:** el menú de herramientas extra tiene un nombre descriptivo propio. Los comandos y sus alias no cambian.
- **Ventanas gráficas:** las capas congeladas en una ventana gráfica ya no se pueden seleccionar ni mostrar pinzamientos dentro de ella.
- Mejoras en el texto de líneas múltiples y en las fuentes SHX, y la lectura de DXF y DWG más robusta.

### Notas
- La app de macOS no está firmada ni notarizada por Apple. La primera vez, haz clic derecho en Forja dentro de Aplicaciones, elige **Abrir** y confirma.

## English

### What's new
- **Blocks palette:** open a folder of drawings or a drawing file as a library, filter its blocks, view them as icons of several sizes or as details, and click one to place it. You can repeat the placement or insert it already exploded.
- **Polish:** the interface is available in Polish.
- **Greek keyboard:** a command typed with the Greek layout active (for example ΛΙΝΕ) works like its Latin name (LINE).
- **Additional Tools:** the extra tools menu has a descriptive name of its own. Commands and their aliases are unchanged.
- **Viewports:** layers frozen in a viewport can no longer be selected or show grips inside it.
- Better multiline text and SHX fonts, and sturdier DXF and DWG reading.

### Notes
- The macOS app is not signed or notarized by Apple. The first time, right-click Forja in Applications, choose **Open**, and confirm.
